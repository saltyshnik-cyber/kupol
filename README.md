# Купол: Telegram-бот и Mini App

Бот для учебного центра и поставщика «Купол» (Красноярск). Что умеет:

- **Обучение:** квиз «какое у вас образование?», карточки курсов с ценами и программами, заявка менеджеру одним нажатием.
- **Каталог:** препараты и косметика из канала. Инъекционные препараты, ботулотоксины и мезотерапия видны только после проверки диплома.
- **Диплом:** пользователь присылает фото, администратору приходит карточка с кнопками «Одобрить / Отклонить», после одобрения каталог открывается.
- **Модели:** анкета (ФИО, телефон, зона, фото лица) уходит администратору; в Mini App видно расписание ближайших процедур с ценами.
- **Согласие на обработку персональных данных** перед любой анкетой (152-ФЗ).

Состав: `Next.js` на Vercel (Mini App + webhook бота), `grammY`, `Neon Postgres`.

## Запуск за 20 минут

### 1. Бот в Telegram
1. В @BotFather: `/newbot`, имя «Купол», username например `kupol_study_bot`. Сохраните **токен**.
2. Узнайте свой Telegram ID у @userinfobot. Это `ADMIN_IDS`. Если заявки должны идти в рабочую группу, добавьте туда бота и возьмите ID группы (отправьте в группе `/whoami`), это `ADMIN_CHAT_ID`. Если группы нет, `ADMIN_CHAT_ID` = ваш ID.

### 2. GitHub и Vercel
1. Распакуйте архив. В репозиторий на GitHub загружайте **содержимое** папки `kupol-bot` (файлы `package.json`, `README.md` и папки `app`, `lib`, `data`, `public`…), а не сам архив и не папку `kupol-bot` целиком. После загрузки в корне репозитория должны быть `package.json` и папка `app`.
   Способ без командной строки: на странице репозитория **Add file → Upload files**, выделить всё внутри распакованной папки и перетащить в окно браузера.
2. На vercel.com: **Add New → Project → Import** этот репозиторий. В поле **Framework Preset** должно стоять **Next.js**. Если стоит Other, поменяйте (Settings → Build and Deployment → Framework Preset → Next.js) и сделайте Redeploy.
3. В проекте: **Storage → Create Database → Neon (Postgres)**. Vercel сам добавит переменную `DATABASE_URL`.
4. **Settings → Environment Variables**, добавьте:

   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от BotFather |
   | `WEBHOOK_SECRET` | любая длинная случайная строка (латиница, цифры, `_`, `-`) |
   | `NEXT_PUBLIC_BOT_USERNAME` | username бота без `@` |
   | `ADMIN_IDS` | ID администраторов через запятую |
   | `ADMIN_CHAT_ID` | куда слать заявки |
   | `SITE_URL` | адрес проекта, например `https://kupol-liart.vercel.app` |

5. Нажмите **Redeploy** (Deployments → три точки у последнего → Redeploy), чтобы переменные подхватились.

### 3. Таблицы и подключение бота (одна ссылка)
Откройте в браузере один раз:

```
https://<ваш-сайт>/api/setup?key=<значение WEBHOOK_SECRET>
```

Страница ответит `"ok": true`: таблицы созданы, бот подключён, кнопка меню настроена. Запускать повторно безопасно (например, после смены адреса сайта). Теперь откройте бота и нажмите `/start`.

Через командную строку то же самое делают `npm run db:migrate` и `npm run bot:webhook` (нужны `vercel link` и `vercel env pull .env.local`).

> **Свой домен.** Для надёжности подключите домен (Vercel → Settings → Domains), например `app.kupol.group`, и пропишите его в `SITE_URL`, затем снова `npm run bot:webhook`. На адреса `*.vercel.app` у части российских провайдеров бывают проблемы с доступом.

## Работа с Claude Code

```bash
cd kupol-bot
claude
```

Claude Code сам прочитает `CLAUDE.md` (структура проекта и правила) и увидит команды:

- `/update-content <папка с html>`: обновляет курсы, товары и расписание моделей из свежего сохранения каналов.
  Страницы каналов сохраняются так: откройте `https://t.me/s/kupolmodel` и `https://t.me/s/kupol_cosmetic` в браузере, прокрутите вверх (подгрузится история), «Сохранить как…» → HTML.
- `/release`: проверяет проект и выкатывает на Vercel.

Примеры задач для Claude Code:
- «Добавь в каталог новый препарат X, он для врачей»
- «Поменяй цену курса сестринского дела на 45 000 ₽»
- «Добавь в бота кнопку “Акции” со списком текущих акций»
- «Сделай рассылку подтверждённым специалистам о новом семинаре»

Каждый push в `main` автоматически деплоится на Vercel.

## Как этим пользоваться администратору

- Диплом приходит в `ADMIN_CHAT_ID` карточкой с кнопками ✅ / ❌. Пользователь получает уведомление.
- Заявки на курсы и анкеты моделей приходят туда же.
- Команды (только для `ADMIN_IDS`): `/stats` (сводка), `/verify <id>` и `/unverify <id>` (вручную открыть или закрыть доступ).
- Любой пользователь может отправить `/whoami`, чтобы узнать свой ID.

## Разработка

```bash
npm install
cp .env.example .env.local   # заполнить
npm run dev                  # Mini App на http://localhost:3000
npm run smoke                # автотест сценариев бота и API (без Telegram и БД)
npm run typecheck && npm run build
```

Бот работает через webhook, поэтому для проверки живого бота локально нужен туннель (например, `ngrok http 3000`): укажите его адрес в `SITE_URL` и выполните `npm run bot:webhook`.

## Что нужно уточнить у клиента

- Цена и формат курса «Косметик-эстетист» (в канале не указана).
- Цена «Врачебной эстетической косметологии»: в канале 45 000 ₽, в проектной документации ~79 000 ₽ за 504 ак. ч.
- Цены на препараты и спеццены для верифицированных: заполняются в `data/products.json` (`price`, `priceB2b`).
- Юридический текст `/privacy`: реквизиты оператора, сроки хранения данных (сейчас шаблон).
