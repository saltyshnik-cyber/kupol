# Купол: Telegram-бот и Mini App

Проект для АНО ДПО «Краевой учебный центр косметологии и массажа «Купол»» (Красноярск, kupol.group).
Три задачи: запись на обучение, закрытый B2B-каталог препаратов и косметики, сбор базы моделей.

## Стек
Next.js 15 (App Router, TypeScript) на Vercel · grammY (webhook `/api/bot`) · Neon Postgres (`@neondatabase/serverless`, SQL без ORM).
Mini App = главная страница `app/page.tsx` (вкладки: Обучение, Каталог, Модель, Профиль).

## Где что лежит
- `data/courses.json`: курсы, семинары, преподаватели (цены, даты, программы).
- `data/products.json`: каталог. `restricted: true` = виден только верифицированным (диплом одобрен). Поля `price` / `priceB2b` пока пустые почти везде: цен в канале нет, заказ идёт через @kupolkosmetic.
- `data/events.json`: расписание приёма моделей (канал @kupolmodel). Прошедшие даты Mini App скрывает сам.
- `lib/config.ts`: контакты, адрес, график, телефоны.
- `lib/bot.ts`: все сценарии бота (согласие 152-ФЗ, квиз по образованию, заявка на курс, анкета модели, диплом, команды админа).
- `lib/tg-auth.ts`: проверка подписи `initData`. Все `/api/*` для Mini App обязаны её использовать.
- `db/schema.sql`: таблицы users, diplomas, leads, model_applications.
- `scripts/smoke.mts`: автотест сценариев на PGlite (`npm run smoke`). Запускай после любых правок бота или API.

## Правила
- Контент (курсы, цены, товары, даты) меняется в `data/*.json`, не в компонентах.
- Закрытые товары нельзя отдавать без проверки `is_verified` на сервере. Фильтровать только на клиенте нельзя.
- Фото дипломов и лиц моделей хранятся только как Telegram `file_id`, в публичное хранилище их не выкладывать.
- Тексты для клиентов только на русском, без канцелярита. Деньги в формате `45 000 ₽`.
- Перед коммитом: `npm run typecheck && npm run smoke && npm run build`.
- Секреты только в переменных окружения Vercel / `.env.local`. В git их не класть.

## Команды Claude Code
- `/update-content`: обновить курсы, товары и расписание моделей из свежего экспорта каналов.
- `/release`: проверить проект и выкатить на Vercel.

## Известные допущения (уточнить у клиента)
- Цена «Врачебной эстетической косметологии» взята из постов: 45 000 ₽ (в проектной документации была ~79 000 ₽ за 504 ак. ч., в канале такого нет).
- Цена курса «Косметик-эстетист» в канале не указана.
- Процедуры для моделей в канале платные (оплачивается препарат), а не бесплатные.
- `/privacy` это шаблон, текст должен утвердить юрист клиента.
