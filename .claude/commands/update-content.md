description: Обновить курсы, товары и расписание моделей из свежего экспорта Telegram-каналов
argument-hint: <папка с сохранёнными .html страницами каналов>
---

Обнови контент проекта из свежих выгрузок каналов Купол (папка: $ARGUMENTS).

1. Запусти `python3 scripts/extract-channel.py $ARGUMENTS /tmp/posts.json` и изучи посты канала моделей (`kupolmodel`) и основного канала (`kupol_cosmetic`).
2. **Модели → `data/events.json`.** Оставь только будущие даты (сегодняшняя дата по Красноярску, UTC+7). Берись за самую свежую версию поста на каждую дату: время окошек и цены в канале обновляются. Формат записи смотри в файле.
3. **Обучение → `data/courses.json`.** Обнови `nextStart`, цены и программы по последним постам про курсы и семинары. Новые семинары добавляй с `audience`, `price`, `duration`, `summary`. Прошедшие разовые семинары не удаляй, а ставь `nextStart: "Ближайшие даты уточняйте"`.
4. **Каталог → `data/products.json`.** Добавь новые препараты и бренды из постов. Инъекционные препараты, ботулотоксины и мезотерапия получают `restricted: true`. Цены вписывай только если они прямо указаны в постах.
5. Ничего не выдумывай: если данных в постах нет, оставь поле пустым или «по запросу».
6. Выполни `npm run typecheck && npm run smoke`. В конце коротко перечисли, что добавлено, изменено и убрано, и отдельно что сомнительно.
